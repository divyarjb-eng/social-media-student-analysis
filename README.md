## Social Media Impact on Student Learning, Sleep & Mental Health
DS 2010: Intro to Data Science — Iowa State University (2025)
Team Project

### Overview
Analyzed 705 student responses from a Kaggle dataset to explore 
how social media usage affects academic performance, sleep, and mental health.

### Tools
Python, pandas, scikit-learn, seaborn, matplotlib

### Key Findings
- Strong negative correlation between usage and sleep hours (-0.79)
- Strong negative correlation between usage and mental health scores (-0.80)
- Students with higher usage more likely to report negative academic impact

### Model
Built and compared logistic regression and KNN classifiers to predict 
academic impact. Logistic regression achieved 95% accuracy using 
stratified cross-validation.
